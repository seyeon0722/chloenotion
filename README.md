# chloenotion

Small HTML widgets, published with GitHub Pages from the `main` branch (site root).

Each widget is a single file:

`https://seyeon0722.github.io/chloenotion/<name>.html`

In Notion, type `/embed` and paste that URL.

## Widgets

- [hello](hello.html) — greeting, clock, and a daily line
- [mood](mood.html) — daily mood log — https://seyeon0722.github.io/chloenotion/mood.html
- [mood day](mood-day.html) — one day of the mood log; `?day=sun` through `?day=sat` pins it to a weekday — https://seyeon0722.github.io/chloenotion/mood-day.html
- [focus-record](focus-record.html) — spinning-record focus timer — https://seyeon0722.github.io/chloenotion/focus-record.html
- [focus-martini](focus-martini.html) — martini-glass focus timer — https://seyeon0722.github.io/chloenotion/focus-martini.html
- [deadlines](deadlines.html) — deadline countdown — https://seyeon0722.github.io/chloenotion/deadlines.html
- [focus-tally](focus-tally.html) — this week's finished focus rounds — https://seyeon0722.github.io/chloenotion/focus-tally.html
- [good record](good-record.html) — small good moments kept as tracks; `?demo=1` shows sample entries — https://seyeon0722.github.io/chloenotion/good-record.html
- [matchbook](matchbook.html) — each small good moment strikes a match; `?demo=1` shows sample entries — https://seyeon0722.github.io/chloenotion/matchbook.html
- [first thing](first-thing.html) — one small thing to start tomorrow; `?day=sun` through `?day=sat` pins it to a weekday; `?demo=1` shows sample text — https://seyeon0722.github.io/chloenotion/first-thing.html
