# chloenotion

Small HTML widgets, published with GitHub Pages from the `main` branch (site root).

Each widget is a single file:

`https://seyeon0722.github.io/chloenotion/<name>.html`

In Notion, type `/embed` and paste that URL.

## Widgets

- [hello](hello.html) — greeting, clock, and a daily line
- [mood](mood.html) — daily mood log — https://seyeon0722.github.io/chloenotion/mood.html
